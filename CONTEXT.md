# Domain Context: html2rss-web

- **Session:** Frontend owner of Access Token persistence (rehydrate / save / clear until Logout) and feed-creation gate predicates from API Metadata (`feed_creation.enabled`, `access_token_required`). Exposes `mayCreate` / `feedCreationEnabled`; does not own route transitions (App navigates to create after logout).
- **Access Token:** Secret token authenticating feed creation. Durable copy lives only in Session storage; sent via Authorization header on create. Ephemeral gate draft must clear on cancel, logout, and create remount — never in COPY, logs, or view-model dumps.
- **Feed Flow:** Sole frontend journey owner for create → submit → token prompt → result / error. Owns the closed UI kind set and `navigate(...)` transitions (auth rejection → token route; unmatched result → create without prefill). Distinct from backend `ErrorClassifier::Decision` and Creation IO.
- **Creation IO:** Network-only feed create (`requestFeedCreation` / `useFeedCreation`). Accepts a normalized URL; owns no journey kind, navigation, or user-facing copy.
- **Auto-Submit:** Initiates feed creation only when `prefillUrl` is passed to the route (e.g., bookmarklet). Bare create remount without `prefillUrl` never auto-submits.
- **Create-Time URL Expansion:** Single frontend normalization path (`expandCreateUrl`) before Creation IO. Feed Flow maps empty/invalid field errors from COPY.
- **Catalog Find:** On create, `findCatalogEntries` matches the query against the catalog (URL equivalence after `expandCreateUrl`, plus case-insensitive substring on `title`/`description`/`id`/`channelUrl`). Capped hits render as a subordinate list under the URL field via `catalogFeedHref` (path + param defaults). Create stays primary; browse stays on the docs Feed Directory.
- **CreateEntry remount:** Visiting create (including `#!/…` → `#/…`) bumps `createEntryKey` to remount the create surface without auto-submitting unless `prefillUrl` is present.
- **Unmatched result:** A `#/result/:token` route whose in-memory created `feedToken` does not match the route token. Feed Flow replaces to create without prefill.
- **Renderer:** `Feeds::Renderer` owns the feed HTTP envelope, success serialization, plain-text error bodies (`ErrorClassifier::Decision#message` on empty feeds), and orchestrates `Feeds::FormatNegotiation` (`FormatNegotiation::MediaRange` for Accept scoring).
- **Responder:** Backend feed route orchestration: resolve → render → emit `feed.render` from `RenderResult` fields only (`Decision` + `Diagnostics`). Exception `emit_failure` is for failures outside a completed Service result.
- **Decision:** `ErrorClassifier::Decision` owns HTTP status, code, client message, kind, cacheability, and retry metadata. Required on every non-ok `Feeds::Contracts::RenderResult` (fails closed). Shared by feed serve and API create/error paths (`ErrorResponder` for JSON, `Feeds::Renderer` for plain text).
- **Diagnostics:** `ErrorClassifier::Diagnostics` owns gem strategy-attempt dig and transport-meta expansion on empty/hard-error `RenderResult` outcomes; read by Renderer and Observability without re-digging.
- **Create-Time Extraction:** Feed creation runs `Feeds::Service` before minting a feed token, failing closed on empty and reusing the warmed `Feeds::Cache` entry on `:ok`.
- **Observability:** Product telemetry (`event_name` + `outcome`: `auth.*`, `feed.*`, `request.error`, `cache.lifecycle`, `config.validation`). No IP or user-agent.
- **Security Logging:** Audit channel (`event_name` with IP, user-agent, token hash for auth, rate-limit, token usage). Auth requires dual-emit with Observability.
- **LogEvent:** Shared emit plumbing (`RequestContext`, `LogSanitizer`, `AppLogger` / Sentry) for Observability and Security Logging; not a public facade.
